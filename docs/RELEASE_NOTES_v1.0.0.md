## iPad Gamepad v1.0.0

First public release. Use an iPad or phone as a customizable touch controller (keyboard/mouse or Xbox) for Windows PC games.

**Download** `iPad-Gamepad-v1.0.0-windows.zip`, unzip the whole folder, run `iPad Gamepad.exe`, then open the address shown in the dashboard on your device and pair with the code.

### Highlights
- Touch layout editor with profiles and presets (Default, Mobile FPS, Phone Controller, Phone Controller (Sticks)).
- Keyboard and mouse output, optional virtual Xbox 360 pads (one per device, more than four allowed), right-stick look, sprint options, aim smoothing.
- Multiple devices with pairing, host and controller roles.
- Desktop app with tray icon and a live PC dashboard (devices, our pads, real controllers read-only).
- KB/M only mode that never loads the virtual-controller driver client.

### Notes
- Windows 10/11 only. The exe is **not code-signed**, so SmartScreen may warn.
- Xbox features need the [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases) driver, which is **not included** and is end-of-life.
- Traffic is plain HTTP on your local network: use trusted home Wi-Fi only.
- Online games with anti-cheat may ignore the input or ban accounts. Use at your own risk; do not use it to gain an unfair advantage.
